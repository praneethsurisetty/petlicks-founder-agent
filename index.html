Execution safeguards

Confirmed customer money: counted only when explicitly marked paid with a positive amount. Veterinary interest: not a partnership without commitment. Clinical care: personalized nutrition guidance requires an appropriately qualified professional.

Quick Update classifies one item at a time using transparent rules; verify the category before saving. For mixed updates, split into separate entries. No autonomous follow-ups are sent or calendar events created by this downloaded file.

Google Sheets automation — integration

Link this app to the Apps Script deployed from your Petlicks Founder Tracker. The matching backend file creates a unified Event Log and appends categorized records to the relevant tabs.

Browser cross-origin restrictions: sent requests can receive an opaque response. A successful network submission does not prove that Google Sheets saved it. Use the agent's event IDs to verify rows in Google Sheets. The backend deduplicates retries. Do not publish the sync URL or shared key.
